# hero image slot

Drop the **hero** image for the README into this folder (any filename).

- Single image: drop one file here (`png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`).
- Light/dark pair (opt-in): drop two files matching `*-light.*` + `*-dark.*` or `light.*` + `dark.*`.

Then re-run the readme-article-expander skill to fill the `hero` slot from this folder.
